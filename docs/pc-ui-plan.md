## 现在的问题（1440×900 实测）

| 量到的 | 数 | 说明 |
|---|---|---|
| 右栏 | 392 px 宽，一条长页 | 造型 11 栏排成 4177 px，要滚 5 屏多；摆姿势 3762 px，「现成的姿势」一栏就 1307 px |
| 标题区 | 120 px，排在最前 | 标题、语言、主题、新手引导、GitHub 地址；用得很少，每次滚到顶都占着 |
| 导出那一排 | 132 px，常驻底部 | 6 个按钮 + 一句话。1280×720 下右栏露出来的设定只剩约 460 px，导出占掉两成 |
| 「身体样式」 | 在第 6 栏，约 2700 px 深 | 白模人台 / 二次元素体 / 成品角色是最先要定的，却要滚 3 屏才找到 |
| 长说明 | 每栏都有一两段 | 「姿势」「头发」「排布」开头都是一大段小字，看过一次就不用再看 |
| 点中部件 | 右栏滚到「手动微调」 | 滚走了就回不去原来在看的那栏，取消选择后还停在微调 |
| 3D 视图上 | 左上模式 + 三个读数牌子，左下视角 + 撤销重做 + 骨骼，右下提示 | 撤销、重做混在视角按钮中间；读数牌子压在模型头顶那块 |

## 新版面（样稿 A）

一句话：**顶上一条薄工具栏，右栏左边一竖排栏目图标，点哪个右栏就只显示哪一栏。**

```
┌─────────────────────────────────────────────────────────────────────┐
│ OC 白模工坊 [造型|摆姿势] ↶撤销 ↷重做      1.77m · 8.2头身 · 15万面 [导出▾] ⋯ │ 48 px
├───────────────────────────────────────────────┬────┬────────────────┤
│                                               │ 描述│ 部件数量   说明 │
│                                               │ 预设│                │
│                    （模型）                    │ 数量│  这一栏的内容   │
│                                               │ 排布│  （只这一栏）   │
│                                               │  …  │                │
│ [头 2 ✕]                                      │────│                │
│ [正面 侧面 背面 斜侧] [骨骼]            提示  │ 镜头│                │
└───────────────────────────────────────────────┴────┴────────────────┘
```

1. **顶栏**（48 px，横贯整个窗口）：名字（小字）、造型/摆姿势、撤销、重做；右边是读数（一行灰字，不再是三个牌子）、「导出」按钮、「⋯」。
2. **栏目条**（68 px）：图标 + 两个字的短名，和手机版用同一套名字和图标。造型时 8 栏、摆姿势时 4 栏，横线下面是两边共用的「镜头」「参考图」「配置」。造型、摆姿势各记各的上次停在哪一栏。
3. **一次一栏**：右栏只显示选中的那一栏，栏名做成大标题；内容长了只在右栏里滚。
4. **说明收起来**：每栏的长说明默认不显示，右栏标题旁「说明」一点全部打开（记住开关）。
5. **导出**：常驻那一排撤掉，换成顶栏右边的「导出 ▾」，点开是一张小面板（大的「导出白模（GLB）」、其余 5 种、那句「怎么导进 Blender」）。状态消息改成从 3D 视图顶上冒一下的小条，几秒后自己消失。
6. **「⋯」菜单**：语言、主题、新手引导、GitHub 地址。标题区不再占右栏。
7. **选中就跳过去**：点中部件 → 切到「微调」；点中关节 → 切到「姿势」；取消选择 → 回到原来那一栏。
8. **3D 视图上只留**：左下视角四个 + 骨骼、选中部件的牌子；右下提示。撤销重做搬去顶栏。

## 另一种做法（B：栏目条 + 长页，没选）

栏目条一样，但右栏还是一条长页：点图标滚到那一栏，滚动时栏目条跟着亮当前那栏。好处是能一路往下翻、什么都看得到；坏处是长页还在（5 屏），点中部件还是滚走。顶栏、导出、说明收起这几条两种做法一样。

## 实现（2026-11-05，照样稿 A）

在 worktree `F:\Downloads\多tool-desk`、分支 `ui/desktop` 上做，从 `rework/torso-bust` 的 c0335f3 切出来。前后对比：`docs/pc-ui/done.jpg`（「改前 · 摆姿势」那张是在主目录截的，里面「几对手臂」那一行是别的会话还没提交的功能，这个分支上没有）。

- 验过：1920×1080、1440×900、1280×720、1000×700、手机横屏 812×375、手机竖屏 375×812（和以前一样，引导 13 步、导出面板都正常）；英文、日文、深色；点部件 / 关节切栏和取消回去、刷新后回到上次的栏、引导走完回到原来那栏、Esc / 点别处 / 再点按钮关弹出层；`tsc`、全部 1633 个测试过。
