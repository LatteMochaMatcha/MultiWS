## 为什么换

- **胸**：一直把胸当成单独的一块，用距离场拼回躯干。接缝上圆角小就是一道折，大就鼓一团，换个胸的大小又坏。10-31 晚到 11-01 换了五六种做法都是这样。
- **多上半身**：一天半换了五个目标形状（树杈、宽胯直立、从胯分、并成一块、各坐各的胯），每碰到一种组合就加一组只对它起作用的常数（`animeLayout.ts` 和 `torsos.ts` 里八十多个大写常数）。组合是乘出来的，补丁追不上。
- **过程**：10-31 之后没提交过，三方（两个 Claude 会话、Codex）同改一批文件。

## 胸的新做法

胸不再是拼上去的一块，而是「躯干表面附近的一层形状」：

1. 每个参考素体（素体原装的小胸、DJP Sculpt 的中胸、DJP 01 的大胸）先算它自己「把胸抹平」的样子：躯干按「高度 × 绕竖轴的角度」展开成半径图（`build-torso.ts` 已有这一步），胸那一片照周围补平。
2. 在「沿表面横着量多远、多高、离抹平的表面往外多远」这三个坐标里，把参考素体原样采成一块格子。离表面的距离按半径图直接算，不用躯干格子的值（`body.bin` 的距离只存到 3.2 cm，大胸凸出十几厘米）。
3. 用的时候，把这块格子按同样的三个坐标贴到我们的躯干上。因为是三维的，胸底和肚子之间的空隙原样保留；胸根的过渡也是从参考素体上原样搬来的，不再靠调圆角。
4. 大小：滑块在小、中、大三种胸型之间渐变，2.2 以上把大胸型放大。下排胸、C/D 正中的胸，都是同一块往别处贴。
5. 分部件模式：从同一个形状上只取胸那一块（离抹平的表面往里 1 cm 以外），封成单独一块插在躯干上。

要拆掉的旧东西：`bust`/`bustLarge`/`bustReference` 三块格子和取胸的那套（`build-bust.ts` 的 SINK、SIDE、MEDIAL），`animeLayout.ts` 的 BUST_SINK、BUST_ROOT、FLESH、LARGE_FROM/LARGE_EASE，`bustSag.ts`，`field.ts` 里只给胸用的单向圆角。

## 风险和应对

| 风险 | 应对 |
|---|---|
| 胸的新做法没试过，可能不行 | 第 2 期只在离线渲染里试，看着不行就停，不动工坊 |
| 胸底的缝太窄，格子分辨率不够，缝会糊掉 | 胸的格子用 2–3 mm 一格；窄到 1 cm 以下的缝不保证 |
| 胸贴得离手臂很近（A 参考图里下面一对手抱着肚子），融合时可能粘在一起 | 验收图专门看这个角度 |
| 融合变慢 | 第 1 期记下改前耗时，每期对比 |
| 摆姿势重新融合、蒙皮权重：胸变成躯干的一部分以后，权重从脊柱和胸的骨骼来 | 第 3 期查导出到 Blender 的权重 |
| 你浏览器里存的设定，胸的手动微调会被重新贴到身上 | 位置可能差一点；已导出的文件不受影响 |
| 别的会话或 Codex 又改这几个文件 | 06f351 已答应不碰；Codex 请你别派它改这块 |
