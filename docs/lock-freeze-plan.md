# 锁定、冻结重做方案

2026-11-28。已经推上 main 的 8bfc79f 和还没提交的「冻结 ▾」下拉，照这份重做。四期当天都做完了（没提交），最后四件事都照建议定。

## 现在别扭在哪

1. 同一个角色有两种「冻结」：场景清单里的雪花冻结后切不过去；顶栏「整个角色」冻结后切得过去，但什么都改不了。
2. 「锁定」在不同地方意思不一样：场景、道具的锁定是位置不能挪，躯干的锁定是摆姿势时身子不跟着动。
3. 躯干有锁定也有冻结，四肢只有冻结。
4. 冻结躯干、四肢时连体型一起定住了（胸部大小、腰宽、手臂长短……），只想定住姿势时不好用。
5. 冻结的四肢在空间里朝向不变，转腰时手臂不跟着胸口走，看着脱节。
6. 改动被悄悄改回去：套「阿修罗」时头变了，手臂没变，只有状态栏一句话。

## 新规则：只有两个词

| | 意思 | 用在哪 |
|---|---|---|
| **锁定** | 不能挪、不能拖 | 场景里角色站的位置；道具的位置、朝向；摆姿势时身上的某个部位 |
| **冻结** | 什么都不能改 | 整个角色；整个道具 |

体型（滑块、数量）不归锁定、冻结单独管：要么整个角色冻结一起定住，要么照常能改。

## 各处怎么变

### 摆姿势：按部位锁定

- 部位和「现成的姿势 → 套用选项 → 套到哪些部位」是同一套五个：**头、躯干、左手臂、右手臂、腿**。好几对手臂时，「左手臂」是左边所有手臂。
- 放在「摆姿势」面板里：原来的「躯干：锁定」一行，换成「锁定」一行五个勾选框。点中某个关节时，关节的小卡片里也有一个「锁定这个部位」。
- 锁了的部位：
  - 圆点不显示，拖不动。
  - 拖别的部位时它不跟着改：躯干锁了，拖手不会带动腰、胸，胯也不挪（和现在的「躯干锁定」一样）。手臂、腿锁了，转腰时它们**相对身子**保持原样，跟着胸口、胯一起转（改掉上面第 5 条）。
  - 什么都不会改它的姿势：套现成姿势、还原姿势、初始化、左右镜像、「脚踩到地上」、双人动作、道具里的抓住都跳过它。「套到哪些部位」里锁了的那几个灰掉。
  - 套姿势时有部位被跳过，状态栏直接说「跳过了锁定的：左手臂、腿」（改掉上面第 6 条）。
- 体型照常能改：手臂锁了，手臂长短、几对手臂照样能调。
- 腿锁了时「脚留在原地」不起作用（腿不能为了脚留在原地去弯），勾选框灰掉。

### 整个角色：只留一个冻结

- 顶栏的雪花改回一个开关按钮「冻结」（不要下拉），场景清单每一行的雪花是同一个开关，两边一起变。
- 冻结后：
  - 设定全部定住，面板里改角色的几栏变淡、点不了，最上面一条说明带「解冻」按钮（就是现在「整个角色」那样）。
  - 站的位置也挪不了（冻结也算锁定）。道具、双人动作都不动它。
  - **还能切过去**：可以单独看它、单独导出，也能在顶栏解冻（改掉上面第 1 条）。所以也不用再限制「场景里至少留一个没冻结的」。
- 只有一个角色时也能冻结。

### 场景位置、道具：不变

- 场景清单里的锁：站的位置、朝向不能挪，照旧。
- 道具的锁、雪花：照旧（锁定是位置朝向不能挪，冻结是什么都不能改、删不掉）。

### 去掉的

- 躯干冻结、四肢冻结、顶栏「冻结 ▾」下拉。
- 冻结时连体型一起定住的那一套（model/torsoHold.ts 的体型部分、model/freeze.ts 的四肢部分）。
