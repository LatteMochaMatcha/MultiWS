# 手指、脚趾数量和手脚互换：方案

2026-11-07 用户要的三件事：

1. 每只手的手指、每只脚的脚趾有几根，可以调；
2. 手可以换成脚，脚也可以换成手；
3. 加一种「queen conjoined」连体形式（见最后一节）。

用户已经定了：

- 数量先有一个统一的数，多条手臂、腿时**每一条还能单独改**（比如左手 6 指、右手 4 指）；
- 手换到腿上时**手心朝下、手指朝前**，像用手掌走路；
- **先做白模和二次元素体**，成品角色放到最后一期，到时再定鞋子怎么处理。

## 现在的手和脚

| | 手 | 脚 |
|---|---|---|
| 白模人台 | 分指：现成的 VRoid 手（CC0），缝在手腕上；并指：自己捏的手套形 | 自己捏的一块，没有脚趾 |
| 二次元素体 | 同一只 VRoid 手 | 现成的 Kotori 脚（CC BY），五个脚趾，但只有一根「Toes」骨骼 |
| 成品角色 | 角色自己的手 | 角色自己的脚，大多穿着鞋 |

手和脚都不进距离场，是融合完以后缝上去的（`sdf/graft.ts`），所以改手指、脚趾的数量只是改那块现成的网格，不用改融合。

## 第 1 期做完的样子（2026-11-07）

和下面原先的打算有三处不一样，都是试出来的：

- **复制的是无名指，不是中指**。中指两边的指缝一深一浅（指蹼差 1.7 厘米），复制品一条接一条焊上去，手心有一道沟；照中指正中镜像也不行，手掌横着是斜的，镜像过来正中折出一道沟。无名指两边的指缝差不多深，复制品排在无名指和小指之间。
- **手掌、手腕不按条复制**，按条复制会起花纹（手掌是斜的，手腕是一根管子）。现在指根往手腕那边（拇指、食指那一条以外）是原来那只手的手掌，整片横着拉宽或压窄；拉宽的程度在两头逐渐加上去，切口和小指一侧的边缘都不折。手腕跟着宽窄的比例打了折（`WRIST_TAPER`）。
- 只有指节、指蹼、手指那一圈按条复制或拿掉；和手掌之间在指根前那条线上焊起来。指蹼两边深浅不一，焊上以后折翻的小三角面会抹平（`unfold`）。

总数可以设 3–8 根（2 根那种拇指加一根不做）。代码在 `src/anime/digits.ts`，测试在 `tests/digits.test.ts`，3–8 根的对比图在 `docs/digits-hands.png`（`node tools/run.mjs tools/try-digits.ts` 重画）。

接进去的地方：设定 `BodySpec.fingers`；`Graft.digits`；白模（`layout.ts`）、素体（`animeLayout.ts` 手的几行）的手和手指骨骼；摆姿势里多出来的手指叫 `FingerA/B/C`，手势、现成姿势、只记了五根手指的姿势数据里都跟着无名指（`extraFingerTwin`），指尖也有圆点；导出 VRM 时标准的五根照常对上，多出来的作为普通骨骼。界面在「造型 → 排布」的「每只手几根手指」，分指的手才显示。

## 第 2 期做完的样子（2026-11-07）

- 二次元素体的脚（Kotori，五个脚趾、一根 Toes 骨骼）能设 **2–8 个**脚趾。1 个做不了：小脚趾那一侧的脚掌外缘是跟着小脚趾那一条来的。
- 和手共用 `anime/digits.ts` 的 `reshape`（按条拼的那一套抽成了通用的，手、脚各给一份 `StripPlan`）；脚先转到手的方向拼，拼完转回来（`shapeFoot`）。
- 多出来的照**第二趾**复制（它两边趾缝几乎一样深），插在第二趾后面；少了先拿掉第四趾，再拿掉第三趾、第二趾。
- 脚跟、脚踝不跟着变（`wristTaper: 1`），只有前脚掌变宽变窄，脚踝那一圈照旧和腿缝上。
- 压得很窄时（2、3 个）：中间那段最多压到四成（`SQUEEZE_MIN`），脚掌磨平几遍（`SQUEEZE_*`）；焊缝两边落差大时摊得宽一点（`BLEND_SPREAD`）。2 个脚趾时脚底两趾之间还有几道很浅的纹。
- 骨骼不用改（脚趾共用一根）。白模人台的脚是一整块、没有脚趾，不显示这一项；成品角色也不显示。
- 界面：「造型 → 排布」的「每只脚几个脚趾」。对比图 `docs/digits-feet.png`。

## 第 3 期做完的样子（2026-11-07）

设定是统一的两项：`BodySpec.armEnd`（手臂末端 hand / foot）、`legEnd`（腿末端 foot / hand），界面在「造型 → 排布」的「手臂末端」「腿末端」。成品角色这两项变灰（第 5 期）。代码在 `src/anime/swap.ts`，测试 `tests/swap.test.ts`，图 `docs/swap-anime.png`、`docs/swap-mannequin.png`、`docs/swap-hand-bend.png`（`node tools/run.mjs tools/try-swap.ts` 重画）。

- **手臂接脚**：不改形。照「腿上那样」摆——顺着前臂往外当作往下，手臂垂下来时脚底朝下、脚趾朝前（原先方案里写的「脚趾顺着手臂往外伸」改了：和用户定的「腿接手是手心朝下、手指朝前」对称）。缩到和手腕一样粗（两边切口一圈长度的比，约 0.81）。素体用 Kotori 脚（脚趾数照「每只脚几个脚趾」），白模用人台自己那块脚（两个椭球）。骨骼还是 `Hand_L`，没有手指；脚趾不另长骨骼。
- **腿接手**：现成的手照它自己的蒙皮权重把手腕往手背那边弯 90°（对偶四元数），拇指先往四指那边收（只差 0.35 弧度），袖口那一圈 1.2 厘米以内逐渐退回原样、切口一点不动，照旧缝得上（`Graft.mesh = 'palm'`）。手心朝下贴地、手指朝前、往外撇 0.3 弧度，放大到和脚踝一样粗（约 1.24 倍）。拇指不收、不撇的话素体两脚挨得近，两个拇指交叉 6 厘米。白模并指的是人台自己的手（拇指、四指放平，最低点贴地）。
- **整个人往下落**：手腕（脚踝那个关节）离地比脚踝矮（素体约 5 厘米），整个人往下落这么多，身高照旧（和腿长短一样整个人照比例放大一点）。只看人腿；人马、蛛形的兽腿不变。
- **骨骼**：腿上还是 `Foot_L`（从手腕伸到中指根），没有 `Toes_L`；手指前面加 `Leg`（`LegThumb1_L`，中线上的腿 `LegThumb1`），多出来的 `LegFingerA` 跟着 `LegRing`。
- **摆姿势**：腿上的手也认成手（`Hand.limb = 'leg'`），指尖有圆点（「拇指 左脚」这样），「脚踩到地上」照手心踩、手指放平；手势栏只管手臂上的手。导出 VRM：手臂上的 `Hand`、腿上的 `Foot` 照常对上，腿上的手指作为普通骨骼。
- **照姿势重新融合**（白模）：腿上一节一节往下的，也只占上面每个关节往下的那一边（`posedField.ts` 的 `planOf`）。以前只照自己根上那一刀，腿接手（并指）时拇指朝前伸，大腿前面那一片落在它那一边，跟着拇指搬走，扯出一片片薄片。默认、人马、蛛形、左右并排的出图和改之前一模一样。
- 白模并指的手摆「自然站立」照姿势重新融合时多出一两小块，不换手脚也是这样（以前就有），没修。

## 第 4 期做完的样子（2026-11-07）

- 设定 `BodySpec.perLimb`：部件名（`Arm_01_L`、`Leg_01_R`、中线上的腿 `Leg_01`）→ `{ end?, fingers?, toes? }`，没写的跟着统一的（`limbOf`）。存档、撤销跟着 spec 走。
- 摆法（`layout.ts` 的 `ownLimbs`）：先照统一的摆一遍；单独设过的那一条，拿它自己的设法当作统一的再摆一遍整个人，只把那一条的形状、接上去的网格、骨骼换过来，位置不动。几个上半身时手臂会改名（右边那个上半身的手臂叫 `Arm_02_L` 这样），这样照最后的名字设就行，不用动 torsos.ts。同样的设法只多摆一遍。
- 腿有手有脚时：整个人不往下落（只有人腿全接手才落）；接手的那几条照腿长短的办法沿腿拉长（`palmReach`，和手动微调叠在一起，大小相乘），手心落到地上，骨骼跟着。
- 界面：在模型上点一条手臂、人腿，「手动微调」里多一块「这一条的末端」（跟着全部 / 手 / 脚）、「这一条的手指 / 脚趾」（− 数 +，单独设过的多一个「跟着全部」）；勾着「同时调整对侧」时对侧一起改。成品角色、兽腿不显示。
- 图 `docs/per-limb-anime.png`、`docs/per-limb-mannequin.png`（`node tools/run.mjs tools/try-swap.ts limbs` 重画）；overview.ts 加了 A26、M13。
- 二次元素体只要有一条手动微调，身高的数就是另一种量法（1.614 左右），以前就这样，不是这次改出来的。

## 第 5 期做完的样子（2026-11-07）

用户定了：手臂接脚用她自己的鞋；手指数也做，照她自己的手指复制、拿掉。十六个成品角色都穿着鞋，手都是光着的（有的袖子盖到手腕）。

代码在 `src/character/limbEnds.ts`（`reshapeLimbEnds`），assemble.ts 里只加了一处调用：在复制手臂、腿之前改她自己那一对，多出来的手臂、腿、上半身都照改过的复制。只在文件原样的 T-pose 上改。分三步：

1. **手指数**：多了照她自己的无名指复制（新骨骼 `FingerA1_L` …），排在无名指和小指之间、小指往外让；少了先拿掉无名指再拿掉中指，拿掉的那根照权重缩回指根（权重归到手上，骨骼清掉），小指往里挪。指根那里会留一个小鼓包。
2. **复制**：腿接手——把她的手（只要皮肤，袖口挂在手上的那截不要）照权重把手腕往手背弯 90°、拇指收拢，放大 1.2 倍接到脚踝上，手指朝前往外撇；手指骨骼叫 `LegThumb1_L` …，手那根就是腿上的 `Foot_L`。手臂接脚——把她的脚连鞋（平均权重 0.85 以上落在脚上的，裤脚碎边不要）缩到 0.8 倍接在手腕上，往肩膀那边挪 2 厘米，前臂收进鞋口。
3. **去掉**：腿接手的去掉她的脚和鞋（脚趾骨骼清掉）；手臂接脚的只去掉手的皮肤，袖口留着（不然切出一圈碎边），挂在手指上的权重归到手上。

手比鞋矮：最后照最低点落到地面，身高照旧（她的脚底本来就是照最低点量的）。她们都穿着鞋，脚趾数对成品角色不起作用；每条单独设（第 4 期）也还没接到成品角色上，设了会在「顾不上的设定」里提示。测试 `tests/characterSwap.test.ts`，图 `docs/swap-character.png`（`node tools/run.mjs tools/try-swap.ts character vita,noble`）。

## 第 6 期做完的样子（2026-11-07）

用户定了：在本会话做（只加一种新的身体，不改原来的躯干、胸、多胯）；没有腿；三种样式一起做。设定 `BodySpec.conjoined`（none / same / opposite），界面在「造型 → 排布」的「连体」；选了以后腿、尾巴、阴茎、几个上半身都不管。

- **白模人台、二次元素体**（`src/geometry/conjoined.ts` 的 `conjoin`，layout.ts 摆位最开始调用）：照一个上半身、一对人腿摆好，再改：
  1. 躯干在腰最细的地方切开（从正中往两边打射线量半宽，取脊柱起点往下 4、往上 16 厘米里最细的高度）：两个上半身照切口对称，只有在最细处对接侧面才是顺的（切在别处是一道沟或一圈棱，试过）。两边各多留 6 毫米；胯、腿、尾巴、阴茎都不要，Hips 骨骼挪到腰上。
  2. 手臂朝前（趴下以后朝下），往外撇；分指的手换成手腕弯过去的那只（`bentHand`），手心贴地、手指朝头那边；人台的并指手整个绕手腕转过去。脖子、头往上抬 60°。
  3. 腰往上复制一份（Torso_B 挂在 Torso 上，部件、骨骼接着往下编号：Head_02、Arm_02_L、Spine.002 …），绕腰转 180°：同向绕前后的轴；反向绕左右的轴，转的那一点前后取在腰那一圈的正中（取在脊柱上差几厘米，一道台阶），当成别的一类融合（圆滑过渡），手臂改成往它自己身后伸、头不抬。
  4. 整个人绕腰往前趴下 90°；反向的仰面那一头肩膀离地近，整个人绕左右的轴歪一点、量几遍，四只手都踩到地上；最后照最低点落地。
- **成品角色**（`src/character/conjoin.ts`，assemble.ts 在烤姿势之前、之后各调一次）：T-pose 上照腰最细的地方切掉腰往下的（裙摆、垂到腰下的头发也切掉），腰往上连骨骼复制一份转过去，两个上半身的手臂、手腕、脖子、头照上面那样设姿势（第二个照第一个的转法、绕 flip 共轭），和别的姿势一起烤（这时用对偶四元数，手腕不塌）；烤完趴下、找平，照手心落地（袖口垂得比手心低的稍微插进地里）。第二个上半身的脸不跟表情。
- 摆姿势：四条手臂；「脚踩到地上」在没有腿时踩的是静止时就在地上的手（`plantFeet`）。现成的姿势是给站着的身子做的，套上去手会离地，点一下「脚踩到地上」再放回去。
- 导出 VRM：VRM 要一副有腿的人形骨骼，连体导出时照旧报「缺左腿……」（GLB 照常）。
- 测试 `tests/conjoined.test.ts`；图 `docs/conjoined-mannequin.png`、`docs/conjoined-anime.png`（`node tools/run.mjs tools/try-swap.ts conjoined`）、`docs/conjoined-character.png`（`… character vita,noble conjoined`）；overview.ts 加了 A27、M14、C09。
- **姿态**（2026-11-07 用户发了参考图后加的，`BodySpec.conjoinPose`：prone / lie / stand，界面「连体姿态」）：
  - 站着：不趴下；下面那个（第二个上半身）倒立，手举过它自己的头撑地（手腕弯过去、手心贴地、手指朝前），上面那个照原样站着、手臂自然垂着（用户定的）。用户看了说「下面那个太低了」（像用头顶着地）：改成标准的倒立——手臂伸直（手肘原来那点弯也拉直）、竖直、和肩同宽，肩膀往头那边耸起 3 厘米，头往胸口收 35°，头离地明显远了。
  - 躺着（用户定的：侧躺、胳膊肘撑着，照参考图）：整个人绕前后的轴侧过来，两个上半身在腰上各往上翘；靠地那一侧的手臂上臂往下往前斜（竖直朝下的话上臂太长，腰贴不到地）、肘弯到前臂水平朝前贴地，另一只顺着身子侧面搭着（往前伸的话横在胸口上），脖子往正上方回正六成。白模、素体照「撑着的前臂和躯干一样低」两分找翘多少（最多 35°），腰上两个切口之间垫一个和腰一样粗的圆团（翘起来以后底下张开一道楔形的缝）；躯干量最低点用从底下往上打的一排射线（拼的、采样的躯干都行）。成品角色固定翘 22°（每试一次都要重烤一遍姿势），第二个上半身的翘法是给它的脊柱第一节加一个绕腰转的姿势。
  - 平躺（用户随后要的）：整个人往后躺平，第一个上半身仰面朝上；手臂往外张开（正切 1.6，约 58°）、往地上那边斜一点搭在地上（顺着身子放的话两个上半身的手在腰上交叉成 X）。同向两个都仰面；反向的那个趴着，头抬起来（不然脸埋在地里）。界面上原来的「躺着」改叫「侧躺」。
- 还没做：两个上半身各设各的头数、手臂数（现在第二个是照第一个复制的）；每条单独设（perLimb）对第二个上半身的手臂照名字也管用，但没专门测。

## 怎么改数量：照原样复制或拿掉一「条」（最初的打算）

照多腿的胯那次的做法（复制素体原样的胯排开），不自己捏手指：

- 把手从拇指那边到小指那边切成几条，每条是「一根手指 + 它底下那一条手掌」；
- **加手指**：复制中间那条（中指连着它的手掌），插进去，别的往两边挪，手掌跟着变宽；
- **减手指**：拿掉中间的几条，两边合拢，手掌跟着变窄；
- 拇指始终是一根，数量算总数：**2–8 根**（2 根就是拇指加一根手指，像钳子）。5 根就是现在的样子，原封不动。

脚趾也一样：从大脚趾那边到小脚趾那边切成几条，复制或拿掉中间的几条，脚掌前半截跟着变宽变窄。脚趾 **1–8 个**。

骨骼、蒙皮跟着复制。多出来的手指起名照多出来的手臂那样带后缀，摆姿势里的手势滑块：五个滑块照旧，多出来的手指跟两边最近的那根一起弯。指尖圆点每根都有。VRM 导出时，标准的五根手指照常对上，多出来的作为普通骨骼带上（VRM 标准里只有五根手指的位置）。

## 手脚互换

- **手臂接脚**：手腕上接的是脚，脚趾顺着手臂往外伸，脚心朝着手心本来的方向。手势面板里这只「手」就算没有手指。
- **腿接手**：脚踝上接的是手，手心朝下贴地、手指朝前。摆姿势的「脚踩到地上」照手掌的高度踩。
- 白模人台：腿接手用现成的分指手；手臂接脚用人台自己那块脚（没有脚趾）。**想让人台的脚也带脚趾，可以另加一个选项「脚：一块 / 带脚趾」（像手的并指 / 分指那样），用素体那只 Kotori 脚**——要不要做，看用户。
- 骨骼名照所在的肢体起（手臂上还是 Hand_L，腿上还是 Foot_L），所以 VRM 导出的骨骼对应不受影响。

## 界面

- 「造型 → 排布」里手、脚那两块：
  - 手指数、脚趾数两个滑块（统一的数）；
  - 「手臂末端：手 / 脚」「腿末端：脚 / 手」。
- 点一下某条手臂或腿（单独调的那个面板）：这一条自己的手指 / 脚趾数和末端是手还是脚，不设就跟着统一的数。
- 存进配置、能撤销；英文、日文译文一起补。

## 分期

| 期 | 做什么 | 做完能看到 |
|---|---|---|
| 1 | 手指数量（统一的数）：手的网格按条复制或拿掉，骨骼、蒙皮、手势滑块、指尖圆点、导出跟上 | 白模（分指）和素体的手能是 2–8 根手指 |
| 2 | 脚趾数量（统一的数）：Kotori 脚切出每个脚趾，复制或拿掉 | 素体的脚能是 1–8 个脚趾 |
| 3 | 手脚互换：手臂接脚、腿接手，摆姿势和踩地跟上 | 两种样式都能手脚互换 |
| 4 | 每条手臂、腿单独设（点部件的面板），存档、撤销、译文 | 左右、上下排的手脚各是各的 |
| 5 | 成品角色（鞋子怎么处理到时再定） | |
| 6 | queen conjoined 连体（见下一节，可以单独分几期） | 两个上半身在腰上对接、四条手臂撑地 |

每期做完出改前改后的对比图给用户看。

## queen conjoined 连体

用户 2026-11-07 发的参考图：两个上半身在腰那里对接，连成一条横着的身子，两头各一个头、各两条手臂，四条手臂撑在地上，**没有腿、没有胯**。分两种：

- **同向**：两个上半身胸口都朝下、背朝上（参考图就是这种）；
- **反向**：一个胸口朝下，另一个仰面朝上、背朝下（那一头的手臂往身后撑地，像反着爬）。

打算的做法：

- 「腿」那一栏加一种下身「连体（queen）」，选了就没有胯和腿，换成另一个上半身，再选同向 / 反向；
- 静止的样子就是横着的：身子水平，四条手臂垂直撑地，两个头各自抬起来看前方（反向那头的头朝上看）；
- 第二个上半身照「多个上半身」那样复制原样的上半身（素体就是素体的胸背，成品角色是角色自己的），腰上照原样对接，不自己捏；
- 两头的头数、手臂数、胸、角、眼睛、兽耳，照「每个上半身单独设」那一套各设各的；
- 摆姿势：四只手当脚用，「脚踩到地上」照手掌踩；两个上半身各自的脊柱都能弯。

要用户定的：

- 能不能在腰上（两个上半身接缝那里）也加腿，还是这种形式就一定没有腿；
- 三种样式（白模、素体、成品角色）一起做，还是也先做白模和素体。

这一块全在躯干、多上半身里，几乎都是归「胸部、上半身和多胯修复方向」会话管的文件（`animeLayout.ts`、`torsos.ts`、`figure.ts`、`sdf/fork.ts`、`grids.ts`、`field.ts` 等），在哪个会话做要用户定。
