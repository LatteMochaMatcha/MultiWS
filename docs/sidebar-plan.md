## 新的排法

造型 7 栏（现在 6 栏），摆姿势 4 栏不变，场景、视图两边共用不变。

### 造型

| 栏 | 放什么 | 从哪来 |
|---|---|---|
| **起步** | 身体样式（白模人台 / 二次元素体 / 成品角色）、角色、身体描述、预设 | 身体样式、角色从「体型」提到最前；描述、预设从「身体」 |
| **部件** | 一个部件一张卡片，卡片标题上就是数量的加减；展开是这个部件自己的排法、样式、大小 | 「数量」全部 +「排布」里按部件的那些 +「体型」里按部件的滑块 |
| **形态** | 整个身体是哪一种：普通 / 多个上半身 / 连体 / 围成一圈，选了哪种下面才出它的选项 | 「数量」的上半身 +「排布」的连体、围成一圈 +「体型」的每个上半身的角色 |
| **外观** | 体型（性别、静止姿势、7 个整体的滑块，分成整体 / 躯干 / 四肢三小组）+ 头发 | 「体型」剩下的 +「头发」 |
| **微调** | 手动微调 + 网格 | 不变 |
| **场景** | 加小标题：角色 / 位置 / 双人动作 / 文件 | 内容不变 |
| **视图** | 镜头和灯光 + 参考图 | 不变 |

「部件」里的卡片：

| 卡片 | 标题上 | 展开以后 |
|---|---|---|
| 头 | 头 几个 | 多个头怎么长（两个头以上才出）；眼睛、角、兽耳的数量；兽耳形状（有兽耳才出） |
| 手臂 | 手臂 几对 | 多对手臂的排法（两对以上才出）；手的样式；末端接手还是脚；每只手几根手指；手臂长短 |
| 胸 | 胸 几个 | 每排几个；胸部大小 |
| 腿 | 腿 几条 | 三条以上的排法、每副胯几条（用得上才出）；末端接脚还是手；每只脚几个脚趾；腿长短 |
| 尾巴 | 尾巴 几条 | 蓬松、长度（有尾巴才出） |
| 翅膀 | 翅膀 几对 | — |
| 成人部件 | 阴茎 几根 | 软硬、排法、每排几根、阴囊、大小。「显示成人部件」的开关挪进「⋯」菜单，和 AI 助手的开关放一起 |

- 卡片收起时标题下面一行小字写现在选的（「凑成一簇 · 猫耳」），不用展开也看得到。
- 好几个上半身时，「改哪个上半身」放在这一栏最上面，管头、手臂、胸三张卡片。
- 电脑上默认全展开，默认造型下约 660 px，一屏放得下；手机上默认收起，点哪张开哪张。开合记在浏览器里。

「形态」里四选一。现在连体、围成一圈、上半身个数是三个各自独立的选项，谁压过谁写在鼠标提示里（连体时不围，围成一圈时不管几个上半身）；改成四选一以后这层关系直接看得见。存进配置的还是原来那几个字段：选「连体」就是把围成一圈设回「不围」，显示出来的身体和现在一样。每种的子选项各记各的，切走再切回来还在。
