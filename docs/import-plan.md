# 自己导入素材：方案

2026-11-20。用户要的：允许用户自己导入外部素材当道具用，比如别的椅子、桌子、杯子。这是**单独的功能**，和「抓住道具」（`docs/grab-plan.md`）互不依赖。

道具方案（`docs/props-plan.md`）里原来写在「这次不做」的「自己导入 GLB/OBJ」就是这一件。分支还是 `feature/props`。

## 现在是什么样

道具有三种来源，都是工坊自带的：

- 基本体（杆、箱子、台子、球、墙）。
- 低模家具 24 件，打在安装包里。
- 写实款 16 件，点了才从下载站取，取过的存在这台设备的浏览器里。

用户自己的模型放不进来。

能接着用的现成东西：

- **写实款的文件格式**（`src/props/realFile.ts`）：一件一个文件，里面有网格、材质、贴图，面多的另带一份碰撞用的粗网格。显示、刷成灰色、导出带贴图、停在表面、穿插提示都已经认它。
- **存本机**（`src/io/keepFile.ts`）：写实款和用户自己的 VRM 都存在浏览器的 IndexedDB 里。
- **把 GLB 转成那种格式**的做法在 `tools/build-props-real.ts` 里，是给我们自己打素材用的，跑在电脑上不在页面里。

## 总的做法

**导入的素材在页面里当场转成写实款那种文件，存本机，之后和写实款走同一条路。** 这样显示、灰色、导出、碰撞都不用另写一套。

### 入口

- 道具栏里「低模」「写实款」旁边多一栏「我的」。第一格是「导入…」，后面是导入过的，一件一格带缩略图。
- 电脑上还能把文件直接拖进 3D 视图。
- 手机上点「导入…」出系统的选文件。

### 认哪些文件

| 文件 | 带什么 | 哪一期 |
|---|---|---|
| GLB | 形状、材质、贴图 | 1 |
| OBJ（单个文件） | 只有形状 | 2 |
| STL | 只有形状 | 2 |
| zip 包、一次选好几个文件（.gltf + .bin + 贴图，.obj + .mtl + 贴图） | 形状、材质、贴图 | 3 |
| FBX | 形状、材质、贴图 | 3 |

网上下的素材多半是 zip 包或者 FBX，所以放进第 3 期，不是不做。读 FBX 的库大，用到才载，不拖慢打开。

带骨骼、动画的文件：取静止的样子，当成不动的东西。

### 导入那一下

选了文件以后出一个导入框，里面有预览：

- **大小**：自动量。大得离谱、小得离谱的照毫米、厘米、英寸猜一次，换成米。框里显示宽、高、深，能改（锁着比例）。
- **朝向**：躺着的（Z 朝上的文件）点「转正」；正面不对的点「转 90°」。
- **原点**：自动挪到底面正中，和别的道具一样。
- **名字**：默认是文件名，能改。
- **分类**：椅子、床、桌子、别的（和现成素材一样的四类），默认「别的」。选了椅子、桌子，一键动作就知道该找坐面还是台面。
- 点「导入」：转格式、出缩略图、存本机、放进场景。

读不了的文件说清是哪里读不了（不认的格式、文件坏了、里面没有网格），不能白屏。

### 存在哪

- 文件存在这台设备的浏览器里，**不上传**，不离开这台设备。
- 清单（名字、分类、大小、缩略图）也存本机。
- 编号用文件内容的校验值：同一个文件导两次是同一件。

### 存档、保存的姿势

只记编号和名字，不带文件。

- 这台设备上打开：素材还在本机，直接用。
- 换一台设备打开：缺的那几件先用同样大小的灰箱子顶着，提示缺哪几件。重新导入同一个文件，自动对上。

想「一个文件带走整个场景」得另做场景包，这次不做。

### 碰撞、一键动作

- 面数多的转格式时另做一份简化的（做法照 `build-props-real.ts`），给「停在表面、穿插提示」用。屏幕上看的是原样。
- 一键动作：导入的没有「哪是坐面、哪是台面」的记号。照分类和形状自动找：椅子找最大的朝上平面当坐面、它后面高出来的那块当靠背；桌子找最高的大平面当台面；床找最大的平面。找不准时按钮是灰的并说原因。
- 手扶、背靠不用记号，哪件都行。

### 大小上限

- 50 MB、20 万个三角面以内直接导。
- 再大的先提示「这件很大，会卡」，用户确认了才导。
- 贴图长边超过 2048 的缩到 2048 再存（省地方，手机上也带得动）。

### 颜色

默认原样（带贴图）；现成的「刷成灰色」照用。只有形状的（OBJ、STL）是白模灰，能改颜色。

### 导出

GLB 带上（含贴图）；OBJ、STL 只有形状。授权是用户自己的事，导出时不替他写署名。

### 删除

「我的」里每件能删。这个场景里正用着的不让删，先说哪几件在用。别的存档里用着的管不了：删了以后打开那些存档，和换设备一样提示缺素材。

### AI 助手

能放已经导入的（种类清单里带上「我的」），不能替用户导入文件。

## 分期

每期照老规矩：测试、类型检查、译文、电脑和手机两种版面、出对比图，等用户看过再做下一期。

### 第 1 期：导入 GLB

- 「我的」一栏、导入框（预览、大小、转正、名字、分类）、缩略图。
- 页面里把 GLB 转成写实款那种文件；存本机；刷新以后还在。
- 放进场景、挪、转、改大小、刷成灰色、撤销、存档、导出。
- 删除；存档里缺素材时用灰箱子顶着并提示。
- 验：带贴图的 GLB、不带贴图的 GLB、毫米单位的 GLB 各一件；刷新；换一个空的浏览器打开存档；导出的 GLB 里有它。

### 第 2 期：OBJ、STL，碰撞和一键动作

- OBJ（单个文件）、STL。
- 拖文件进 3D 视图。
- 面多的做简化的碰撞网格；大文件的提示；贴图缩到 2048。
- 照分类自动找坐面、台面、靠背，接上一键动作。
- 验：导入一把椅子能「坐上去」，一张桌子能「撑着」；20 万面的文件拖手不卡；手机上能选文件、能导。

### 第 3 期：zip、多文件、FBX，收尾

- zip 包、一次选好几个文件（.gltf + .bin + 贴图，.obj + .mtl + 贴图）。
- FBX（读它的库用到才载）。
- AI 助手的种类清单带上「我的」。
- 新手引导补一句、译文、README、使用说明、全套测试。旧内核、模拟器、打包等用户说发版时做。

## 这次不做

- 导入带骨骼的角色当角色用（那是「成品角色」的 VRM，另一回事）。
- 场景包（一个文件带走场景和里面导入的素材）。
- 导入的素材在设备之间同步。
- 在工坊里改导入的模型（拆件、删面、改材质）。
- 3MF、PLY、Blender 的 .blend 等别的格式。

## 风险

- **导入的文件什么样的都有**：单位、朝向、面数、坏掉的网格、几百张贴图、透明材质。导入框里能改大小、能转正；材质只认底色、法线、粗糙度金属度这几样，别的丢掉，如实说。
- **页面里转格式**：`build-props-real.ts` 是给电脑上跑的工具写的，搬到页面里要重看一遍（内存、读贴图的办法不一样）。大文件转的时候页面会卡一下，要给进度。
- **本机存得下多少**：浏览器给每个网站的地方有限，手机上更少。存不下要说清，不能悄悄丢。
- **旧内核手机**（WebView 83）：以前踩过缺函数、贴图坏的坑，导入这条路要在旧内核上单独验。
- **自动找坐面**：导入的椅子千奇百怪，找不准是常事。有退路（按钮灰着说原因，用户自己摆）。
- **FBX**：格式版本多，读不了的会不少。读不了时提示「在 Blender 里另存成 GLB 再导」。

## 做成了：第 1 期，导入 GLB（2026-11-20）

- **道具栏多了「我的」一栏**（「现成的家具」最后一组）：第一格是「导入…」，后面是导入过的，带小图，右上角的 ✕ 是删除。
- **导入框**（`src/view/propImport.ts`）：带贴图的预览；「转正」（往上翻 90°）、「转 90°」（绕竖直轴）；名字（默认是文件名）；分类；宽、高、深（厘米，三个数锁着比例）；下面一条条写着读的时候丢掉、改掉了什么。
  - 单位照最长的那一边猜（`guessUnit`）：当成米在 2 厘米–10 米之间就是米，不然试厘米、毫米，落在 2 厘米–4 米之间的算数，都不像就缩放到半米。猜的是什么写在框里。**猜不准是常事**：95 毫米高的杯子会被当成 95 厘米，要用户自己改。
  - 导入以后最长的一边收在 1 厘米–10 米之间（道具能设的范围）。
- **转格式在页面里做**（`src/props/importMesh.ts`，纯函数）：照节点的摆放把所有网格拼成一整块，原点挪到底面正中，一样的点合成一个，同一个材质的面排在一起，写成写实款那种文件。之后显示、刷成灰色、导出带贴图、停在表面、穿插提示走的都是写实款现成的路，没另写。
  - 没带法线的现算；镜像过的节点面的绕向反过来；带骨骼的照文件里骨骼现在的摆放算成不动的样子（动画不要）。
  - 材质只带底色、底色贴图、法线贴图、粗糙度金属度贴图。透明和镂空画成不透明的，刷在点上的颜色、第二套贴图坐标、贴图的平铺偏移不带——碰到了都在导入框里说一声。
  - WebP 的贴图导入时转成 PNG（导出的文件别的软件才认）。
  - 读不了的直接说原因：不是 GLB、网格压缩过（Draco、meshopt）、要用到外面的文件、里面没有网格、超过 200 万个面。
- **碰撞用的粗网格**提前到这一期做了（方案里排在第 2 期）：超过 1500 个面的另做一份，做法是把空间切成小格子、同一格里的点并成一个（`clusterMesh`），没用 `build-props-real.ts` 里的 meshoptimizer（它是 three 的类型包顺带装进来的，不该进页面）。偏离原来的表面不超过半个格子。
- **编号**是 `my-` 加原文件内容 SHA-256 的前 16 位：同一个文件在哪台设备上导入都是同一个编号。浏览器不给 `crypto.subtle` 时（用局域网地址打开）自己算，结果一样（`src/io/sha256.ts`）。
- **存在哪**（`src/props/userStore.ts`）：IndexedDB，和写实款、用户的 VRM 一处。每件一个文件，另有一份清单（名字、分类、大小、小图）。存不了时这一次照样能用，状态栏说「关掉以后要重新导入」。
- **存档**：道具上只记编号和放下时的名字（`SceneProp.assetName`）。这台设备上没有那件时用同样大小的方块顶着，状态栏说缺哪几件；选中它有「重新导入…」。重新导入同一个文件，方块换成真的样子，不另放一件，大小照存档里的。
- **同一个文件再导一次**：不出导入框，直接放一件，说一声「想换大小、朝向先删掉再导」。
- **删除**：这个场景里正用着的不让删，说是哪几件在用；没在用的问一句再删。
- **导入的素材能薄到 1 毫米**（别的道具是 1 厘米）：刀刃、一张纸不会被撑厚。
- **导出**：GLB 带上它和它的底色贴图。场景里有导入的素材这台设备上没有时，导出会停下来说缺哪几件（不把方块导出去）。
- AI 助手已经能放「我的」里的（`create` 认编号），但种类清单里还没列出来，留到第 3 期。

## 做成了：第 2 期，OBJ、STL，一键动作（2026-11-20）

- **OBJ、STL 能导了**（`src/props/importShape.ts`，纯函数）：读出来的和 GLB 是同一种东西，后面定大小朝向、转成素材文件是同一条路。
  - OBJ：点、面、法线、贴图坐标都读；多边形的面照扇形拆成三角；倒着数的下标认。**旁边的 .mtl 和贴图不读**（要一次选好几个文件，第 3 期），导入框里说一声。
  - STL：二进制的、文字的都认。文件里每个面各带三个点，先把一样的点合起来（照坐标的二进制原样比，不拼字符串，几百万个角也不卡）。
  - 没带法线的现算：共用一个点、朝向差不到 50° 的面算同一片光滑的面，再大就是棱（`cornerNormals`）。箱子的棱还是棱，圆柱的侧面还是圆的。
  - **STL 默认先「转正」**：这种文件差不多都是 Z 朝上，导入框里说了，不对再点一次。
  - 这两种只有形状，清单里记着 `plain`：放下来就是「刷成灰色」的样子，和基本体一样能挑颜色，选中时不出「刷成灰色」那个勾。
- **拖文件进窗口**（`main.ts`）：整个窗口都接，不只是 3D 视图。拖进来的不是这三种时状态栏说一声（原来浏览器会把页面换成那个文件，现在拦住了）。
- **大文件先问**：超过 50 MB 或 20 万个面，问一句「导进来拖动时会卡，手机上可能带不动」，取消就不导。超过 200 万个面的还是直接不让导。
- **贴图缩到 2048**：最长的一边超过 2048 像素的缩到 2048，JPG 还存成 JPG（质量 0.9），别的存成 PNG；导入框里说缩了几张。
- **照形状自己找坐面、台面、床面**（`src/props/autoContacts.ts`，纯函数）：从上往下看切成 36×36 格，量每一格最高的面（一张高度图），高度差不多、连成一片的格子算同一层。
  - 「桌柜」：最上面那一层是台面（也能坐）；最上面那层太小（桌上带架子、挡板）就用下面面积最大的那一层。
  - 「坐的」：最上面那层占了一大半就是凳子、长凳，坐最上面，哪边都能坐；不然面积最大的那层是坐面，比它高出一截的是靠背，脸背着靠背。够 1.2 米长的还能躺。
  - 「躺的」：面积最大的那层是床面，床头板在哪头头就朝哪头，没有床头板顺着长边躺；坐在两条长边上。
  - 「别的」什么都不找。圆的（占外接方块不到 86%）认成圆的。
  - 找出来的东西和手工标的是同一种（`PropContacts`），一键动作那边没改；`propContacts` 里现成的家具照标的，导入的照找的，找过一回记着（照网格记，分类改了重找）。
