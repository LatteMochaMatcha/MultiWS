# 抓住道具：方案

2026-11-20。用户要的：手或脚能吸附、抓在道具上（比如抓着杆子），移动别的肢体时保持抓着；两个方向都要——道具固定（人在公交车上拉着杆），或者道具跟着人（拿着盒子、抱着盒子）。

同一天用户又加了一条：**允许自己导入素材**（道具方案里原来写在「这次不做」的）。

接在道具七期（`docs/props-plan.md`）后面做，同一个分支 `feature/props`。七期开工前已经提交。

## 现在是什么样

第 4 期做了「钉住」：摆姿势时选中手、脚，旁边 12 厘米内（脚 16 厘米）有道具，就出「钉在「杆 1」上」。

- 钉上以后：挪道具，那只手跟着走（只动那一条手臂）；拖胯、拖别的肢体，那只手留在道具上。
- 连接记在角色身上（`SceneFigure.links`，`src/model/links.ts`），只记**位置**：道具表面上最近的一点，加上离那一点多远。
- 第 7 期的「吊着」「腿缠杆」里手指会翻过杆握住（`propActions.ts` 的 `grip`），只认杆，只在这两个动作里用。

缺的：

| 缺什么 | 现在的样子 |
|---|---|
| 手掌朝向 | 钉上以后道具转了、歪了，手掌不跟着转 |
| 手指握住 | 自己钉的手是原来的手形，不会握 |
| 吸附 | 要先把手拖到跟前再点按钮，拖近了不会自己吸过去、不会转过去对着表面 |
| 道具跟着手 | 没有。「手里拿的东西」当时写在「这次不做，留了接口」里 |
| 两只手拿、抱着 | 没有 |
| 手够不着时拉住身体 | 钉着的脚会把胯拉住（`settleRoot`），钉着的手不会：拖胯拖远了，手臂伸直以后手就离开道具悬着 |

## 借来的做法

查的结果见会话记录，这里只记用上的。**只借思路**；AutoGrip 是 MIT，别的是 GPL 或者付费的说明页。

- **谁带着谁**（游戏里拿武器）：道具挂在一只主手上跟着走，别的手反过来钉在道具上。抱着 = 道具挂在胸口，两只手钉在道具上。不用解「手—盒子—手」的环，现有的钉子就够。
- **抓取面**（Meta 的 VR 交互 SDK）：一个握法在整个面上都能用。杆是圆柱面（沿着杆滑、绕着杆转），桌沿和盒子的棱是一条线，平面是整张面。手靠近时手腕吸到面上最近的地方。
- **手指一节节弯到碰着**（AutoGrip，Quick Finger Collision 是同一回事）：一个 0–1 的握紧度管全部指节。
- **接上、换方向不跳**（Dynamic Parent）：记的是手和道具的相对位置，两个方向用同一份，切换时两边都不动。
- **先伸手、到了再挂上**（Final IK 的交互）：一键动作里先让手够到道具，再切成道具跟着手。

闭环的 FABRIK（Aristidou 2016）不用：要换求解器，「谁带着谁」够了。

## 总的做法

### 一个「抓住」记什么

在现有的连接上加三样，都可省（旧的连接照样读）：

- **朝向**：手（脚）相对道具怎么转的。道具转了、歪了，手跟着转。
- **握紧度**：0–1。手指形状不存，每次照道具表面重算（道具改了尺寸，手指自己跟着合上）。
- **道具跟着**：开了就是道具跟这个部位走；不开是道具不动、这个部位跟道具。

位置还是现在的记法（表面上一点 + 离多远）。两个方向用的是同一份相对位置，所以切换那一下谁都不跳。

### 两个方向各是什么表现

| | 道具不动（公交车拉杆） | 道具跟着（拿着盒子） |
|---|---|---|
| 拖这只手 | 手沿着道具表面滑；拖开超过一段距离就松开 | 道具跟着手走、跟着手转 |
| 拖胯、拖别的肢体 | 手留在道具上；手臂伸直了，身体就被拉住 | 道具跟着身体走 |
| 挪道具（操纵杆、改数） | 手跟着道具 | 手跟着道具（等于拖这只手） |
| 整个角色挪位置 | 手留在道具上 | 道具跟着角色走 |

也就是说挪道具永远是「手跟着」，开关管的是「人动的时候道具留下还是带走」。

### 带着的道具的位置存在哪

这是这次最要小心的地方。现在道具的位置存在场景的道具清单里，有自己的撤销；角色的姿势是另一条撤销。

做法：**带着的道具，位置照那个部位现算，不往道具清单里写**。

- 显示、导出、查穿插、别的角色找它，都问一句「这件道具现在在哪」（带着的照手算，没带着的读清单）。
- 拖手、拖胯时道具清单没变，只是角色的一步撤销。
- 放下（关掉「道具跟着」、松开、删角色）那一下，把算出来的位置写回清单，和角色那一步并成一步。
- 一件道具只能跟一个角色的一个部位。别的手、别的角色可以再钉在它上面（它们跟着道具）。
- 不许绕圈：人整个跟着椅子时，椅子不能再跟着这个人的手。

### 吸附

拖手的圆点时，手腕进到道具表面 6 厘米以内（照身高放缩）就吸过去：

- **杆、细长的东西**：手腕到杆的侧面，手掌对着杆心，手指绕过去。绕哪边、朝上握还是朝下握，取离现在手的朝向最近的。
- **平面**：手掌贴着面（撑着、扶着），手指朝现在的方向。
- **棱**（桌沿、盒子边、椅背顶）：手掌在一个面上，手指翻过棱扣到另一个面上。离棱 4 厘米以内才算。
- **球**：手掌贴着球面。
- **脚**：脚底贴着面，不握。斜板、台阶上脚掌跟着面转。

吸上去时道具上亮一圈提示；松手那一下建好连接、手指握上。吸着的时候继续拖是沿着表面滑；拖开就松开（现在的规则）。

摆姿势的工具条上加一个「吸附」开关，默认开。

先做基本体（杆、箱子、台子、球、墙），再做素材（椅子、桌子、沙发）。素材是网格，平面和棱照「最近的点和那里的朝向」通用地算；细的部位（椅子腿、扶手、栏杆）当杆抓要另外认，做不稳就只当平面抓，如实说。

### 手指

把 `grip` 从「只认杆」改成认任何道具：每节指骨一点点弯，指尖碰到道具表面就停（道具表面的距离现成有，`solidDistance`）。拇指从另一边合过来。握紧度 1 是握到碰着，0 是原来的手形，中间是半握。

选中抓着的手时，卡片上多一个「握紧」滑块。

### 两只手、多只手

- **两只手拿一件带着的道具**：一只是主手（道具跟着它），另一只钉在道具上。
  - 拖主手：道具跟着，另一只手被带着。
  - 拖另一只手：道具绕着主手抓的那一点转过去，两只手都还抓在原处。
  - 两只手之间的距离是定死的（都抓在道具上），拖不开；硬拖开超过松开的距离，那只手松开。
- **抱着**：道具跟着胸口，手都钉在道具上。拖手等于手在道具上换地方抓。
- **三只以上的手**（多臂角色）：主手带着道具，别的都钉着。拖别的手只在道具表面上滑，不转道具。

### 够不着时

道具不动、身体被拖远：手臂伸直以后把身体拉住（和钉着的脚拉住胯一样）。拖的那一处到此为止。

整个角色被挪远（拖底座圈、改位置的数）拉不住：手臂伸直朝着道具，够不着就悬着，状态栏说一声（现在就是这样）。

### 界面

- 「钉在「杆 1」上」改叫「抓住「杆 1」」（脚是「踩住」），合成一个功能，不另加一套。
- 抓着以后那一行：一句话 + 「道具跟着手」开关 + 「握紧」滑块 + 「松开」。
- 道具那边「连着它的」每行标出方向（「跟着它」/「带着它」）。
- 手机上都在选中关节的小卡片里，排不下的收进一行。

### 自己导入素材

用户自己的模型文件当道具用。下面这些是我定的，用户只说了「允许自行导入」。

- **入口**：道具栏里「低模」「写实款」旁边多一栏「我的」，第一格是「导入…」。电脑上还能把文件直接拖进 3D 视图。
- **格式**：GLB（带贴图）、OBJ、STL。读这三种的库 three.js 自带。
  - FBX 第一版不做：读它的库大，文件里常带骨骼和动画。要的话后面单加。
  - 带外部文件的 .gltf 不做（要一次选好几个文件）。
- **导入那一下**：
  - 读成不动的网格；带骨骼、动画的取静止的样子。
  - 量大小。大得离谱、小得离谱的照毫米、厘米、英寸猜一次，换成米。导入框里显示宽、高、深，能改。
  - 原点挪到底面正中（和别的道具一样）。躺着的（Z 朝上的文件）点「转正」。
  - 出一张缩略图。
- **存在哪**：这台设备的浏览器里（IndexedDB，和写实款、用户自己的 VRM 存在一处）。文件不上传，不离开这台设备。
- **场景存档、保存的姿势**：只记这件素材的编号（文件内容的校验值）和名字，不带文件。换一台设备打开，提示缺哪几件；重新导入同一个文件，自动对上。
- **碰撞和吸附**：面数多的另做一份简化的，给「停在表面、穿插提示、吸附」用；屏幕上看的还是原样。
- **大小**：50 MB、20 万个三角面以内直接用；再大的先提示会卡，用户确认了才导。
- **颜色**：默认原样（带贴图）；现成的「刷成灰色」照用。
- **导出**：GLB 带上（含贴图），OBJ、STL 只有形状。授权是用户自己的事，导出时不替他写署名。
- **一键动作**：导入的没有「哪是坐面、哪是台面」的记号。照形状自动找最大的那块朝上的平面当坐面、台面；找不准时按钮照常是灰的、说原因。抓、踩、吸附、手扶、背靠不用记号，都能用。
- **删除**：「我的」里能删。这个场景里正用着的不让删，先说哪几件在用。
- **AI 助手**：能放已经导入的（种类清单里带上「我的」），不能替用户导入文件。

## 分期

每期照老规矩：测试、类型检查、译文、电脑和手机两种版面、出对比图，等用户看过再做下一期。不提交，等用户说。

### 第 0 期：准备

- 把现在钉住的行为用测试钉死（已有 25 条，补够不着时的）。
- 「道具现在在哪」收成一个函数，显示、导出、穿插、跟随都走它。这一期它只读清单，样子不变。
- 看得见的变化：没有。

### 第 1 期：抓住带朝向、够不着拉住

- 连接加朝向；道具转了、歪了，手掌、脚掌跟着转。
- 钉着的手伸直了把身体拉住。
- 按钮改名「抓住」「踩住」。
- 验：杆歪 30°，手跟着歪；拖胯拖远，身体停在手臂够得着的地方。

### 第 2 期：手指自己握上

- `grip` 认任何道具；握紧度滑块；脚底贴面。
- 「吊着」「腿缠杆」「手扶着」「撑着」改用同一套，做完带着握紧度。
- 验：抓杆、抓箱子的棱、撑桌面、扶球，三种身体样式各一遍；道具改尺寸以后手指跟着合上。

### 第 3 期：拖近了自动吸

- 基本体的四种抓法（杆、平面、棱、球）；亮圈提示；「吸附」开关；沿表面滑；拖开松开。
- 素材的平面和棱；细部位当杆抓（做不稳就退到只当平面）。
- 验：手机上用手指拖也吸得上；吸附关掉以后和现在一样。

### 第 4 期：自己导入素材

- 「我的」一栏、导入框（大小、转正、缩略图）、拖文件进来、存本机、删除。
- 简化的碰撞网格；自动找坐面、台面；存档只记编号、缺了提示。
- 导出带上导入的素材。
- 放在这里的原因：吸附做完了，导入的网格直接能吸、能抓；后面「道具跟着手」正好拿导入的杯子、剑来试。它和抓住互不依赖，想先要可以提到前面。
- 验：GLB（带贴图）、OBJ、STL 各导一件；毫米单位的文件大小猜对；刷新以后还在；换一个空的浏览器打开存档提示缺素材，重新导入对上；手机上能选文件。

### 第 5 期：道具跟着手

- 「道具跟着手」开关；带着的道具位置现算；放下时写回；撤销、重做、存档、刷新。
- 导出（GLB、OBJ、STL）、保存姿势带道具、别的角色、双人动作都认带着的道具。
- 带着的道具穿进身体只提示（现成的穿插提示），不硬拦。
- 验：一只手拿着小箱子，拖手、拖胯、挪角色、换姿势，箱子都跟着；来回切方向不跳；撤销每一步都对。

### 第 6 期：两只手拿、抱着

- 第二只手钉在带着的道具上；拖另一只手道具绕主手转；多臂的规则。
- 道具跟着胸口。
- 验：两手端着箱子拖任一只手；抱着箱子弯腰；四臂角色四只手抓一根杆。

### 第 7 期：一键动作和收尾

- 一键动作（只给一副胯、有手臂的，和现在一样）：「拿着」（单手）、「两手端着」、「抱着」、「举过头顶」。照道具大小自己挑抓的地方，做完自动建好连接。
- 「手扶着」加一种：头顶的横杆够得着时站着拉住（公交车）。
- AI 助手：抓住、松开、切方向三个工具；监控快照带上方向。
- 新手引导那一步补一句；译文；README、使用说明；全套测试；旧内核、模拟器、打包等用户说发版时做。

### 以后（用户说了再做）：自带一批能单手拿的小东西

杯子、手机、剑、伞、书这一类素材。用户定了先不下：用缩小的基本体（最小 1 厘米，箱子缩小就是盒子，杆缩短就是棍子），加上第 4 期自己导入的。要自带的话先列清单（来源、授权、大小），等用户点名再下载。

## 这次不做

- 两个角色一起抬一件东西（一件道具只跟一个角色；另一个角色可以钉在它上面，但拖它不会带动道具）。
- 道具有重量、会掉、会倒。
- 手指以外的身体去贴合道具（抱着时手臂、胸口不会压进软的东西里）。
- 成品角色的裙摆、头发不认道具。
- 多胯、人马、围成一圈等形态的一键动作（抓住、吸附本身不挑形态，多臂能用）。

## 风险

- **两条撤销**：带着的道具放下时要写回道具清单，和角色那一步并成一步。道具第 4 期的 `History.amend` 是反方向的（道具那步带上角色的改动），这次要再做一个方向，撤销的先后顺序（`editOrder`）不能乱。
- **「道具现在在哪」**漏改一处，就会出现屏幕上跟着、导出没跟着。第 0 期先收口就是为这个。
- **素材上的吸附**：网格没有「这是一根杆」的记号，细部位认不准。有退路（只当平面）。
- **手指握到各种形状上**：会有握不上、握穿的，每种身体样式（白模手是现成的手网格、成品角色各家的手不一样）都要出图看。
- **拖动时的速度**：吸附每一帧要量手到所有道具的距离；带着的道具每一帧要重摆。写实款面数多的要先用包围盒筛。
- **导入的文件什么样的都有**：单位、朝向、面数、坏掉的网格、几百张贴图。导入框里能改大小、能转正；读不了的要说清是哪里读不了，不能白屏。
- **导入的素材不跟着存档走**：换设备要重新导入。用户要是想「一个文件带走」，得另做场景包，这次不做。

## 已定的事（2026-11-20 用户说「都按建议来」）

| 事 | 定的 |
|---|---|
| 道具不动、身体拖远了够不着 | 身体被拉住 |
| 吸附 | 默认开，工具条上有开关 |
| 两只手拿着时拖其中一只 | 道具绕另一只手转过去 |
| 「钉在…上」和「抓住」 | 合成一个，改名「抓住」「踩住」 |
| 小件手持物素材 | 先不下，用缩小的基本体和自己导入的 |
| 开工前先提交七期 | 先提交（已提交） |
| 自己导入素材 | 要做（用户加的）。怎么做见上面「自己导入素材」，细节是我定的，用户没逐条表态 |
