# VRM 导出：方案

2026-11-03 他定了：VRM 0.x、多出来的手臂在软件里不动、白模默认「只许自己用」。

**进度**：第 1 期做完（2026-11-03）——`src/io/vrm.ts`（写 VRM 0.x、人形骨骼对照表）、`writeGlb` 加了「骨骼不转」和扩展、导出栏「VRM」按钮和填作者许可的小框、尾巴的弹簧骨骼；
T-pose 是把静止的网格照权重搬过去（权重本来就是手臂平举着算的）。好几个上半身时人形表取第一个上半身，它里侧的手臂当右手臂。
在 Blender 的 VRM 插件里导入检查过白模人台双头四臂、二次元素体、两个上半身。

第 2 期做完（2026-11-03）——`src/character/vrm.ts`：成品角色照给的 T-pose 蒙皮矩阵搬成 T-pose；脸单独一个物体，原文件的每个变形是一个形态键（几张脸一起动），表情组照原文件绑；MToon 照原文件抄（按材质名，染过的头发按比例换亮面、暗面；法线、高光、自发光贴图没读，不带）；眼睛进人形表、视线范围照原文件；meta 照原文件（作者加「改」，出处写改自原角色和署名）。`source.ts` 读的时候留下 MToon 和 meta；`writeGlb` 加了形态键，扩展可以拿到最后的材质、贴图、网格下标。小框里成品角色不能选许可。Blender 里查过橙发校服两个头、kuro。

第 3 期做完（2026-11-03）——`source.ts` 读 VRM 0.x 的弹簧骨骼和碰撞球（方向照 UniVRM 的存法，换成面朝 +Z 是 x 取反）；`assemble.ts` 拼的时候给每根骨骼记一笔是文件里哪根来的（`CharacterBuild.origins`，复制出来的也记原来那根）；`character/vrm.ts` 的 `springsOf` 照它把每一组搬到拼好的骨架上：复制出来的头上的头发、多排的胸、多出来的手臂上的袖子各自从自己的根晃，碰撞球每一份骨骼挂一组（照子骨骼的方向转、照骨骼间的距离缩放）；换上的发型文件里没有设定，整副一组，照角色自己的头发。原文件每组的 center 没带（写 -1）。Blender 里查过橙发校服两个头、绿发红裙四条手臂、银发猫耳换波波头，碰撞球画出来看过。第 4 期没做；载入自己的 VRM 1.0 的弹簧骨骼（VRMC_springBone）留到第 4 期。

## 做成以后是什么样

导出栏里多一个「VRM」按钮。导出的文件拿去 VTuber 软件（VSeeFace、Warudo、VNyan……）、VRoid Hub、Unity（UniVRM）、Blender（VRM 插件）直接能用：

- 人形骨骼认得出来：头、脖子、脊柱、手臂、手指、腿都对得上，面部捕捉、动作捕捉能带着它动。
- 成品角色：贴图、卡通着色照原角色；表情（笑、怒、哭、眨眼、口型）能用，几个头一起做表情；头发、裙摆是弹簧骨骼，跟着身体晃。
- 文件里写着作者、许可、署名，照原角色的条件原样带上（见下面「许可」）。

## 现在缺什么（看过代码）

| VRM 要的 | 工坊现在 | 要做的 |
| --- | --- | --- |
| 静止姿势是 T-pose | 默认 A-pose | 导出 VRM 时临时按 T-pose 算一张（白模重新融合，成品角色重新拼），姿势不进文件 |
| 骨骼节点不带旋转（VRM 0.x） | 带骨骼 GLB 里每根骨骼转成沿着骨头的方向（给 Blender 画骨骼用） | 写文件时加一个「骨骼不转」的写法 |
| 面朝 −Z（VRM 0.x） | 面朝 +Z | 写之前整个绕竖轴转 180° |
| 人形骨骼对照表 | 骨骼名本来就照 VRM / Unity 起的（`Hips`、`UpperArm_L`、`Index1_L`…） | 直接对：只对第一套（见下面「多出来的部件」） |
| 表情：形态键 + 表情组 | 表情是烘在网格上的 | 写文件支持形态键；每个表情算一个形态键，绑进 VRM 的表情组 |
| 卡通材质（MToon） | 导出时换成了普通材质 | 照角色原文件的 MToon 参数写回去；白模用单色的 MToon |
| 弹簧骨骼、碰撞球 | 读角色时没留 | 读的时候留下来，拼的时候跟着改名、复制 |
| 作者、许可 | GLB 只写一句署名 | 照原角色的 meta 写；白模在导出时填 |

## 多出来的部件

VRM 的人形骨骼只有一套：一个头、两条手臂、两条腿。多出来的部件这样放：

- **第一套进人形表**：第一对手臂、第一个头（几个头凑成一簇时是正中那个）、第一对腿、第一个上半身。
- **别的挂在骨架上，不进人形表**：多出来的手臂、头、腿、尾巴、翅膀都在，跟着身体走，但 VTuber 软件不会去动它们——举手时只有第一对手臂举起来，别的保持 T-pose 时的样子。
- 表情：几张脸绑进同一个表情组，一起笑、一起眨眼。
- 视线：只有第一个头的眼睛跟着转。
- 人马、蛛形：上半身照常进人形表，马腿、蛛腿挂在骨架上。软件会把「腿」认成哪一对，要试过才知道（人马的前腿可能当成人腿）。

想让多出来的手臂也跟着第一对动，VRM 1.0 有「约束」（一根骨骼照抄另一根的旋转），0.x 没有。见「要你定的」第 2 条。

## 分期

1. **白模（白模人台、二次元素体）导出 VRM 0.x**：T-pose 静止姿势、面朝 −Z、骨骼不转、人形表、单色 MToon、meta（导出前填作者、选许可，记住上次填的）、第一人称、署名。尾巴给弹簧骨骼（可以晃）。
2. **成品角色**：贴图和 MToon 照原角色、表情组（几张脸一起）、视线（眼睛骨骼）、meta 照原角色。
3. **弹簧骨骼**：头发、裙摆、衣摆、袖子照原文件的参数；复制出来的头上的头发、多出来的手臂上的碰撞球跟着复制。
4. **收尾**：载入自己的 VRM 也能导、分部件模式不能导（按钮变灰、说明为什么）、README、exe 和手机上试一遍。

每一期做完都在你的 Blender 里用 VRM 插件导进去看（插件已经装了：`extensions/blender_org/vrm`）：人形骨骼对不对、表情能不能拖、弹簧骨骼在不在。另外写一个自己的检查，读回导出的文件，查 VRM 要求的几样都在。

## 要你定的

1. **VRM 0.x 还是 1.0**：我建议先做 0.x。VSeeFace 这些常用的 VTuber 软件只认 0.x；十个角色的原文件也是 0.x，材质、表情、弹簧骨骼照抄就行。1.0 以后可以再加。
2. **多出来的手臂在 VTuber 软件里不动**，能接受吗？不能的话要做 1.0（用「约束」让它们照抄第一对），工作量多一期，而且只有支持 1.0 约束的软件才认。
3. **白模的作者和许可**：导出前弹一个小框填作者名、选许可。许可默认我想用「只许自己用」（Redistribution_Prohibited），你要发出去再自己改成 CC0、CC BY 之类。可以吗？
